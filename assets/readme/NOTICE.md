# France 24 Playback Screenshots

`watch.png` and `matrix.png` contain broadcast frames captured for 227 TV
application documentation on October 21, 2026. The production app decoded France
24 French for the fullscreen view and four distinct language feeds (French,
English, Arabic and Spanish) for the matrix. These are native PC screenshots,
not handheld captures, performance measurements or audio verification.

The unchanged website [capture record](captures.json) preserves URLs, timestamps,
observed frame counts, source formats and source/output hashes for all nine views.
Its `world.png` corresponds to the identical `browse.png` stored here; four other
views remain website-only. See the [gallery's filename mapping](README.md#all-nine-views).

The capture run used network access and actual decoding with null/disabled audio.
It did not access a handheld, controller or personal saved state, and performed
no installation. Browser/search and installer views are scripted states with
authentic station names and sample cards. Viewing these PNGs does not tune streams.
